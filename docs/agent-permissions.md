# PERMISSIONS (Agent OS)

- Agente sem permissão context ou paused/inativo: agentContext bloqueado (F11).
- Assignment checa projetos autorizados no selector; sem autorização o agente é excluído dos candidatos.
- Tools exigidas pela task precisam estar cobertas pelo agent.tools para pontuar; execução real continua gated na F20.
- Approvals (approvals table) cobrem CONTENT/DESIGN/MESSAGE/CAMPAIGN/CODE/EXTERNAL_ACTION/OTHER com resolve approve/reject por humano.
